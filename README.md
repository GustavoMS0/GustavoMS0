#### ⭐ [zabbix-autodiscovery](https://github.com/GustavoMS0/zabbix-autodiscovery) (Python)

- **Topologia Dinâmica no Grafana:** Geração programática de mapas NOC com telemetria viva nos enlaces.

- Clonagem de permissões e grupos em onboarding de novos colaboradores a partir de usuário-modelo.
- Automação de rotinas de backup de caixas postais (Exchange Online) e auditoria de segurança via Microsoft Graph API.

- Substitui listas estáticas por seleção de categorias em árvore cascata, reduzindo erros de classificação e agilizando a triagem de incidentes/requisições.

#### 🛠️ [Install-Gm](https://github.com/GustavoMS0/Install-Gm) (Shell / PowerShell)
